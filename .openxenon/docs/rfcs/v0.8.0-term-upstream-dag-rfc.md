## 0. 背景与动机

当前 Domain term 间引用是**纯文本字符串**（`"OrderItem"`），编译期无法校验：

```oxl
domain "Order" {
  term "Order" {
    property id: "uuid"
    property items: "OrderItem[]"   // ❌ 编译期不检查 OrderItem 是否存在
  }
}
```

v0.8.0 引入 **`@term/X` 跨 term 物理引用** + **`@upstream` 域间 DAG 声明**，让跨域影响分析成为编译期事实：

```
Order ──@upstream──> Product       # 编译期校验循环依赖
Order.items ──@term/OrderItem──> OrderItem  # 物理引用
```

---

## 1. `@term/X` 跨 term 寻址

### 1.1 语法

```oxl
domain "Order" {
  term "Order" {
    property id: "uuid"
    property items: "@term/OrderItem[]"  // 物理引用（同 Domain 内）
  }

  term "OrderItem" {
    property sku: "string"
    property qty: "number"
  }
}
```

### 1.2 校验规则

1. `@term/X` 必须指向**同一 Domain** 内已定义的 term
2. 缺失 → `E_OXL_TERM_NOT_FOUND`
3. 自引用 → `E_OXL_TERM_SELF_REFERENCE`
4. 删除 term X → 所有引用 X 的 term 列出（不阻断，仅 warning）

---

## 2. `@upstream` DAG 声明

### 2.1 语法

```oxl
domain "Order" {
  upstream {
    "OrderItem" -> "@prj/domains/Product/Term/SKU"  // 跨域引用
  }
}
```

### 2.2 校验规则

1. `upstream` 块定义跨域依赖图
2. 编译期拓扑排序（DAG）
3. 循环依赖 → `E_OXL_UPSTREAM_CYCLE`
4. 引用目标不存在 → `E_OXL_UPSTREAM_TARGET_NOT_FOUND`

### 2.3 跨域 Impact Analysis

`oxn domain impact Order`：

```bash
# 列出 Order 的所有下游 + 上游
$ oxn domain impact Order
Downstream (依赖 Order):
  - Shipping (shipping.oxn: Order)
Upstream (Order 依赖):
  - Product (product.oxn: SKU)
  - User (user.oxn: User)
```

## 4. 实现细节

### 4.1 Langium Grammar 扩展

`src/oxl/langium/oxn.langium`：

```langium
Domain: 'domain' name=ID '{'
  (term+=Term)*
  ('upstream' '{' upstream+=UpstreamEdge* '}')?  // v0.8.0 新增
'}';

UpstreamEdge: from=ID '->' ref=CrossRef;  // v0.8.0 新增

Term: 'term' name=ID '{'
  (property+=Property | invariant+=Invariant)*
  ('anchor' '=' anchor=STRING)?  // v0.7.2
'}';

Property: name=ID ':' type=PropertyType;
PropertyType: STRING | TermRef;  // v0.8.0: STRING | '@term/'ID
```

### 4.2 编译器扩展

`packages/engine/src/oxl/md-bridge/compilers/domain-compiler.ts`：

```ts
// 解析 property.type = "@term/X"
if (type.startsWith('@term/')) {
  const termName = type.slice(6).replace('[]', '')
  if (!domain.terms.some(t => t.name === termName)) {
    throw new OxlError('E_OXL_TERM_NOT_FOUND', { termName })
  }
}

// 解析 upstream 块
for (const edge of domain.upstream ?? []) {
  validateCrossDomainRef(edge.ref)  // 校验 @prj/domains/...
}
```

### 4.3 CLI 新增

```bash
oxn domain impact <name>           # 上下游影响分析
oxn domain validate <name>         # 现有 validate + @term/@upstream 校验
oxn domain dag <name>              # 输出 DOT / Mermaid
```
