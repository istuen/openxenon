# v0.7 变更日志片段

> v0.7 是 v0.6.x 之后的首个 major minor 演进，主题是"涌现层骨架（Insight 工程化）"。

---

## 0.7.0 — 涌现层骨架

**发布日期**：2026-11-15（预计）
**核心交付**：Insight 审核闭环 + 跨 Work 模式深化 + Insight 可视化 + Hall v0.5（Vue 组件化）

### 新增功能

- **`oxn insight apply <id>`** — 一键应用 Insight 草案
  - 自动调用 `oxn <kind> validate <name>`
  - 触发 planLock 重算
  - 错误自动回滚（备份 .bak）
- **模式库持久化**（`.openxenon/pools/insight-patterns/`）
  - 跨 Work 模式自动 upsert（新增 / 更新）
  - 30 天归档
  - `oxn insight patterns list/show/promote/archive` 子命令
- **Insight 关系图**（DOT / Mermaid 渲染）
  - L0 纯函数 `buildInsightGraph` 生成 DOT 字符串
  - Hall 端 Mermaid.js 渲染（v0.7 唯一新依赖）
- **Hall v0.5（Vue 组件化）**
  - 6 大 Vue 组件：HealthPanel / InsightPanel / InsightGraph / HooksPanel / PatternsPanel / AssetsPanel
  - 交互能力升级（filter / search / 详情）
  - 路由：`/hall/health/insight/hooks/patterns/assets`
- **强制人工审核保障**：
  - 仍仅 `oxn insight apply` 显式触发
  - 仍可单独 `oxn insight approve` 不 apply
  - OXN_AUTO_APPROVE 警告保留

### 新增模块

- `packages/engine/src/Insight/`
  - `pattern-library.ts` — 模式库持久化
  - `apply-draft.ts` — Insight 草案应用
  - `graph-builder.ts` — L0 关系图构建

### 新增 Vue 组件

- `docs/.vitepress/theme/components/`
  - HealthPanel.vue
  - InsightPanel.vue
  - InsightGraph.vue
  - HooksPanel.vue
  - PatternsPanel.vue
  - AssetsPanel.vue

### 错误码扩展

- `OXNI_INSIGHT_DRAFT_NOT_FOUND`
- `OXNI_INSIGHT_VALIDATE_FAILED`
- `OXNI_PATTERN_NOT_FOUND`
- `OXNI_PATTERN_ALREADY_PROMOTED`
- `OXNI_PATTERN_DUPLICATE`
- `HALL_RENDER_FAILED`

### 依赖

- **1 个新 npm 依赖**：`mermaid`（用于 InsightGraph 渲染）
- 这是 v0.6.x 期间允许的唯一新依赖

### 测试增量

- +31 cases（1,996 → 2,027）

## 关键约束（v0.7 全程遵守）

| 约束 | 含义 | 检验方式 |
|---|---|---|
| **三轴主导权不交叉** | 工程师 / AI / OXN 各司其职 | ESLint |
| **Proof 不可绕过** | Daemon 硬阻断 + 无 `--force` | 单元测试 |
| **AI 不直接反写 Asset** | `oxn insight apply` 仍需人工触发 | code review |
| **轻量级工程边界** | 不破坏 v0.6 收敛的 E1-E4 | architecture-guard |
| **强制人工审核** | 永不自动 apply | 错误码 + 警告 |
| **1 个新依赖上限** | 仅 mermaid | package.json diff |
