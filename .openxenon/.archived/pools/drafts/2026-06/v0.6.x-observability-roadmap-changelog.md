## 0.6.1 — 完整 Daemon 雏形 + Hall 骨架

**发布日期**：2026-08-15（预计）
**核心交付**：Daemon 进程 + 5 类可观测性 + Token 统计 + Insight 流入口 + Hall VitePress 静态站

### 新增功能

- **Daemon 进程**：`oxn daemon start/stop/status/restart/logs`
  - PID file + 自动重启
  - 优雅退出（SIGTERM）+ 5s 强杀兜底
- **Webhook 通知**：7 类事件（work.created / work.locked / work.round.passed / work.round.failed / work.finalized / proof.frozen.drift / insight.promoted）
  - Slack / Discord / 终端 三选一
  - 重试 3 次（指数退避）
- **frozen.json 完整性 watch**：SHA-256 校验 + 篡改告警
- **Work 健康观测**：执行时长 / 轮次 / 失败模式 → health.json
- **Hook 事件流**：所有 Hook 触发 → events.jsonl
- **Token 消耗统计**：每次 Skill 调用的 token 成本
- **Insight 流入口**：Daemon 监听 Work 完成 → 自动落 insight-raw 池
- **Hall VitePress 静态站骨架**：health.md + works.md 两个面板

### 修复

- 无（v0.6.0 已稳固）

### 内部改进

- `src/daemon/` 新增 supervisor / file-watcher / webhook-notifier / insight-sink / health-aggregator / token-recorder 6 个模块
- OXNRC schema 扩展 `daemon` 字段
- 测试增量：+34 cases（1,890 → 1,924）

### 依赖

- **0 个新 npm 依赖**（VitePress 已是 docs 站点依赖）

## 0.6.2 — Insight 收集层（强制人工审核）

**发布日期**：2026-09-05（预计）
**核心交付**：trace 结构化 + insight-raw 池 + CLI 子命令 + 跨 Work 模式初探
**核心约束**：**强制人工审核**——AI 不直接覆盖 Asset

### 新增功能

- **trace.jsonl 结构化**：4 种新事件（asset.violation / intent.drift / round.failed 扩展）
- **Insight 原始池**（`.openxenon/pools/insight-raw/`）
  - hash 链保证不可篡改
  - chmod 0o444 权限
- **CLI 子命令**：
  - `oxn insight list` — 列出所有 raw/audit/archived
  - `oxn insight show <id>` — 详情 + 源头 trace 引用
  - `oxn insight promote <id>` — 提升到 audit pool（不直接覆盖 Asset）
  - `oxn insight approve <id>` — 写 Asset 草案（.oxn.draft），不直接入库
  - `oxn insight reject <id>` — 写回 audit + 标记 rejected
  - `oxn insight archive [--before <date>]` — 归档 30 天前未 review
- **跨 Work 模式自动识别**（L0 纯函数）
  - 阈值：同 Domain + 同 pattern ≥ 3 次
  - 时间窗口：30 天（可配）
  - confidence 评分
- **强制人工审核保障**：
  - `OXN_AUTO_APPROVE` env var + 5s 警告延迟
  - approve 写 `.oxn.draft` 草案，需 `oxn domain validate` 才能正式入库

### 新增模块

- `packages/engine/src/Insight/`
  - `cross-work.ts` — 跨 Work 模式识别
  - `archiver.ts` — 归档逻辑
  - `insight-pool.ts` — raw 池读写
  - `suggestion-generator.ts` — promote 模板生成
  - `types.ts` — InsightRaw / CrossWorkPattern / InsightSuggestion

### 错误码扩展

- `OXNI_INSIGHT_NOT_FOUND`
- `OXNI_INSIGHT_ALREADY_PROMOTED`
- `OXNI_INSIGHT_TARGET_ASSET_MISSING`
- `OXNI_INSIGHT_APPROVE_REQUIRES_MANUAL`（强制人工提示）
- `OXNI_INSIGHT_DUPLICATE_PATTERN`

### 测试增量

- +28 cases（1,924 → 1,952）

## 0.6.3 — Asset 分级 + Token 经济学

**发布日期**：2026-09-26（预计）
**核心交付**：Asset scope 字段 + 上下文注入策略 + OXNRC 配置 + 重复检测 + Hall 观测面板

### 新增功能

- **Asset scope 字段**（OXL grammar 扩展）
  - `always`（每次注入）/ `context`（关键词触发）/ `lazy`（按需）
  - 默认 `always`（向后兼容）
- **上下文注入策略**（`packages/engine/src/Intent/inject-strategy.ts`）
  - L2 统一调度
  - 稳定前缀（always）+ 可变后缀（context）= 高 KV 缓存命中率
  - lazy Asset 提供 query API
- **OXNRC context 段**
  - `tokenBudget`（默认 15000）
  - `cacheStrategy`（aggressive / balanced / minimal）
  - `scopeDefaults`（domain / blueprint 默认 scope）
  - `triggerKeywords`（全局触发词）
- **`oxn config validate`** — 输出预算报告（fits / breakdown / 稳定前缀大小）
- **`oxn config set context.*`** — 6 个子命令
- **Asset 重复检测**（L0 纯函数）
  - 启动期扫描 + validate 时检测
  - warning 级别，不阻断
  - 抽取建议（shared-domain.oxn）
- **Hall 面板**：
  - tokens.md — Token 消耗分布 + KV 缓存命中率
  - duplicates.md — 重复列表 + 抽取建议

### OXL 语法增量

## 0.6.4 — Hook 框架深化（Pre/Post + OXL hook 语法）

**发布日期**：2026-10-10（预计）
**核心交付**：Pre/Post Hook 钩子点 + OXL hook 语法 + disable-model-invocation + Hall 可视化

### 新增功能

- **三时机 Hook**：Pre / Post / Stop（对齐 Claude Code Hook）
  - Pre-Hook：Work run / submit / finalize 前
  - Post-Hook：task.submit / probe.run 后
  - Stop-Hook：Work finalize 前
- **OXL hook 语法扩展**
  - `pre-hook` / `post-hook` / `stop-hook` 声明
  - 4 种 type：shell / probe / deny / ask
  - 失败策略：deny / ask / warn
  - `disable-model-invocation: true`（节省 token）
- **钩子执行器**（`packages/engine/src/Work/hook-runner.ts`）
  - shell / probe 类型直接执行，不调 LLM
  - 失败时按 fail strategy 处理
  - 所有事件写入 events.jsonl
- **Hall 面板**（hooks.md）
  - 渲染 events.jsonl 流水
  - 按 phase / workName 过滤
  - 失败率统计

### OXL 语法增量

```oxl
blueprint "dev-workflow" {
  scope: context
  
  hooks {
    pre-hook "verify-asset-lock" {
      type: shell
      script: "oxn work validate"
      on: work.run
      fail: deny
    }
    
    post-hook "impact-analysis" {
      type: probe
      scheme: "git-diff-stats"
      on: task.submit
      fail: warn
    }
    
    stop-hook "final-typecheck" {
      type: shell
      script: "bun run typecheck"
      on: work.finalize
      fail: deny
      disable-model-invocation: true
    }
  }
  
  slot "build" { ... }
}
```

### Token 节省（参考 Harness Engineering）

- secret-scan hook：每次 Work run 节省 ~500 tokens
- final-typecheck hook：每次 finalize 节省 ~800 tokens
- 全场景累计：每次完整 Work 节省 ~1500 tokens

### 错误码扩展

- `IAP_WORK_HOOK_DENIED`
- `IAP_WORK_FINALIZE_DENIED`
- `IAP_HOOK_SCRIPT_FAILED`
- `IAP_HOOK_INVALID`

### 测试增量

- +16 cases（1,974 → 1,990）
