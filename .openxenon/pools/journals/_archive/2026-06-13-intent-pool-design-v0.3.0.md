### 2.2 生命周期分叉（v3 同 v2）

#### 上游池（research / design / issue）

```
drafting → finalized → consumed
            │
            └─→ archived（软归档）
```

| 状态 | 含义 | 触发 |
|---|---|---|
| `drafting` | 写作中 | `oxn pool create` |
| `finalized` | heading 校验通过 | `oxn pool finalize` 成功 |
| `consumed` | 被 work `--source-pool` 引用 | `oxn work create --source-pool` 自动切 |
| `archived` | 软归档 | `oxn pool archive` |

#### 下游池（audit / journal）

```
drafting → finalized → verified
            │             │
            │             └─→ archived（可选）
            └─→ archived
```

| 状态 | 含义 | 触发 |
|---|---|---|
| `drafting` | 写作中 | `oxn pool create` / `oxn work finalize` 自动建 |
| `finalized` | heading 校验通过 | `oxn pool finalize` 成功 |
| `verified` | 经 proof run 验证 | `oxn pool verify --proof <id>` 注入 verdict |
| `archived` | 软归档 | `oxn pool archive` |

### 2.8 `lifecycle` 字段去掉（v3 修隐患 2）

**v2 错误**：meta.json 有 `lifecycle: "upstream" | "downstream"`，是 `type` 的纯函数。

**v3 修正**：删除字段，CLI 内部推导：

```typescript
// src/cli/pool/lifecycle.ts
export type PoolType = "research" | "design" | "issue" | "audit" | "journal"
export type Lifecycle = "upstream" | "downstream"

const UPSTREAM_TYPES: ReadonlySet<PoolType> = new Set(["research", "design", "issue"])

export function getLifecycle(type: PoolType): Lifecycle {
  return UPSTREAM_TYPES.has(type) ? "upstream" : "downstream"
}

export function isUpstream(type: PoolType): boolean {
  return getLifecycle(type) === "upstream"
}
```

`oxn pool list --lifecycle upstream` 内部等价于 `--type research,design,issue`。

## 3. content.md 模板（v3 全面重写：阻断问题修复）

### 3.1 v2 自相矛盾诊断（必须看明白才能修）

**v2 设计**：
- 通用 4 章：`## 0. 元信息 / ## 1. What / ## 2. Why / ## 3. How / ## 4. 参考`
- 类型特定 heading 追加在 1-3 章之间

**v2 实际生成骨架（journal）**：
```markdown
## 3. How —— 8 阶段流程实测     ← ## 级但带"3. How"前缀
### 3.1 阶段 1：init              ← ### 级
### 3.3 关键经验                  ← ### 级
```

**v2 必填校验**：要 `## 8 阶段流程实测` / `## 关键经验` / `## 提交清单`（**纯文本精确匹配**）

**结果**：3 个必填 heading 全部 miss → finalize 100% 失败

**v2 根因**：通用 4 章与类型特定 heading 抢 `##` 级位次。

### 3.2 v3 修复：每类池独立 ## 级 heading 序列

**v3 规则**：
- 通用章节只有 3 个：`## 0. 元信息` / `## What` / `## 参考`（**无数字前缀**，便于精确匹配）
- 中间全部是类型特定 heading（**直接 ## 级**，不带数字）
- 校验：heading 文本去掉前后空白后精确匹配必填列表（双语任一即过）

### 3.3 5 类池必填 ## 级 heading 序列（v3 SSOT）

| 类型 | 必填 ## 级 heading 序列 |
|---|---|
| **research** | `0. 元信息` → `What` → `现状快照` / `Current Snapshot` → `漂移点` / `Drift Points` → `风险评估` / `Risk Assessment` → `参考` |
| **design** | `0. 元信息` → `What` → `决策记录` / `Decision Record` → `PR 拆分` / `PR Breakdown` → `验收标准` / `Acceptance Criteria` → `参考` |
| **audit** | `0. 元信息` → `What` → `评级总览` / `Rating Overview` → `优秀模式` / `Good Patterns` → `弱信号清单` / `Weak Signals` → `参考` |
| **journal** | `0. 元信息` → `What` → `8 阶段流程实测` / `Phase-by-phase Log` → `关键经验` / `Key Learnings` → `提交清单` / `Commit Summary` → `参考` |
| **issue** | `0. 元信息` → `What` → `现象` / `Symptom` → `根因` / `Root Cause` → `修复方案` / `Fix Plan` → `经验教训` / `Lessons Learned` → `参考` |

**校验实现**：
```typescript
// src/cli/pool/finalize.ts
import { parseHeadings } from "../../infra/markdown-headings"

const REQUIRED_HEADINGS: Record<PoolType, Array<{ zh: string; en: string }>> = {
  research: [
    { zh: "现状快照",     en: "Current Snapshot" },
    { zh: "漂移点",       en: "Drift Points" },
    { zh: "风险评估",     en: "Risk Assessment" }
  ],
  design: [
    { zh: "决策记录",     en: "Decision Record" },
    { zh: "PR 拆分",      en: "PR Breakdown" },
    { zh: "验收标准",     en: "Acceptance Criteria" }
  ],
  audit: [
    { zh: "评级总览",     en: "Rating Overview" },
    { zh: "优秀模式",     en: "Good Patterns" },
    { zh: "弱信号清单",   en: "Weak Signals" }
  ],
  journal: [
    { zh: "8 阶段流程实测", en: "Phase-by-phase Log" },
    { zh: "关键经验",       en: "Key Learnings" },
    { zh: "提交清单",       en: "Commit Summary" }
  ],
  issue: [
    { zh: "现象",     en: "Symptom" },
    { zh: "根因",     en: "Root Cause" },
    { zh: "修复方案", en: "Fix Plan" }
  ]
}

export async function finalize(poolId: string): Promise<Verdict> {
  const meta = await readMeta(poolId)
  const content = await readContent(poolId)
  // 提取 ## 级 heading 文本（去前导数字/空白/前后空白）
  const headings = parseHeadings(content, { level: 2, stripNumber: true })
  // 必填项必须在 headings 集合里（中或英任一）
  const required = REQUIRED_HEADINGS[meta.type]
  const missing = required.filter(r =>
    !headings.has(r.zh) && !headings.has(r.en)
  )
  if (missing.length > 0) {
    return {
      ok: false,
      error: {
        code: "IAP_POOL_FINALIZE_MISSING_HEADINGS",
        axis: "INTENT",
        action: "YIELD_TO_HUMAN",
        message: `Pool ${poolId} 缺少必填二级 heading：${missing.map(m => m.zh).join(", ")}`,
        context: { poolId, missingHeadings: missing, presentHeadings: [...headings] }
      }
    }
  }
  // 写 contentHash + status=finalized
}
```

### 4.2 `oxn work finalize` 两阶段原子写入（v3 修隐患 1）

**v2 错误**：journal 目录创建 + meta.json 写 + content.md 写 无原子性，步骤间失败会留"孤儿池"。

**v3 修正**：临时目录 + 完整性验证 + 原子 rename。

```typescript
// src/infra/pool-journal-generator.ts
import { rename, rm, mkdir, writeFile } from "fs/promises"
import { join } from "path"

export async function createJournalAtomically(args: {
  workId: string
  workState: WorkState
  sourcePoolId: string | null
  poolsDir: string
}): Promise<{ journalId: string }> {
  const { workId, workState, sourcePoolId, poolsDir } = args

  // 1. 计算 journal ID（与 workId 同 slug）
  const journalId = `POOL-J001-${kebabCase(workId)}`  // 实际实现用 sequential numbering
  const finalDir = join(poolsDir, "journal", journalId)
  const tmpDir = join(poolsDir, ".pools", ".tmp", journalId)

  try {
    // 2. 写临时目录
    await mkdir(tmpDir, { recursive: true })
    const skeleton = buildJournalSkeleton(workState, sourcePoolId)
    const meta = buildJournalMeta({ journalId, workId, workState, sourcePoolId })
    await writeFile(join(tmpDir, "content.md"), skeleton, "utf-8")
    await writeFile(join(tmpDir, "meta.json"), JSON.stringify(meta, null, 2), "utf-8")

    // 3. 完整性验证：临时目录能解析、heading 通过、meta schema 合法
    const validation = await validateJournalEntry(tmpDir)
    if (!validation.ok) {
      await rm(tmpDir, { recursive: true, force: true })
      throw new IAPError({
        code: "IAP_POOL_JOURNAL_SKELETON_INVALID",
        axis: "INTENT",
        action: "YIELD_TO_HUMAN",
        message: `Journal skeleton ${journalId} failed validation: ${validation.errors.join(", ")}`
      })
    }

    // 4. 原子移动（rename 在同一文件系统下是原子的）
    await rename(tmpDir, finalDir)
    return { journalId }
  } catch (err) {
    // 5. 异常清理：确保不留孤儿目录
    await rm(tmpDir, { recursive: true, force: true }).catch(() => {})
    if (existsSync(finalDir)) {
      // 如果 finalDir 已存在（重名），清理（不应发生但兜底）
      await rm(finalDir, { recursive: true, force: true }).catch(() => {})
    }
    throw err
  }
}

async function validateJournalEntry(dir: string): Promise<{ ok: boolean; errors: string[] }> {
  const errors: string[] = []
  // 1. content.md 存在
  if (!existsSync(join(dir, "content.md"))) errors.push("missing content.md")
  // 2. meta.json 存在
  if (!existsSync(join(dir, "meta.json"))) errors.push("missing meta.json")
  // 3. heading 校验
  const content = await readFile(join(dir, "content.md"), "utf-8")
  const headings = parseHeadings(content, { level: 2, stripNumber: true })
  const required = REQUIRED_HEADINGS.journal
  const missing = required.filter(r => !headings.has(r.zh) && !headings.has(r.en))
  if (missing.length > 0) errors.push(`missing headings: ${missing.map(m => m.zh).join(", ")}`)
  // 4. meta schema 校验
  try {
    const meta = JSON.parse(await readFile(join(dir, "meta.json"), "utf-8"))
    PoolMetaSchema.parse(meta)  // Zod 校验
  } catch (e) {
    errors.push(`meta.json invalid: ${(e as Error).message}`)
  }
  return { ok: errors.length === 0, errors }
}
```

### 4.3 物理复制 hash 漂移警告（v3 同 v2 修复 R-7）

```typescript
// src/cli/work/validate.ts
export async function validateWork(workId: string): Promise<Verdict> {
  const workState = await readWorkState(workId)
  const sourcePoolId = workState.context.source_pool
  if (!sourcePoolId) return { ok: true, warnings: [] }

  const workCopyPath = join(workDir(workId), "source", sourcePoolId, "content.md")
  if (!existsSync(workCopyPath)) return { ok: true, warnings: [] }

  const workCopyHash = await sha256File(workCopyPath)
  const poolMeta = await readPoolMeta(sourcePoolId)
  if (workCopyHash !== poolMeta.contentHash) {
    return {
      ok: true,
      warnings: [{
        code: "IAP_POOL_SOURCE_HASH_DRIFT",
        axis: "INTENT",
        action: "REVIEW",
        message: `Source pool ${sourcePoolId} has been updated since work creation`,
        context: {
          poolId: sourcePoolId,
          workCopyHash,
          poolCurrentHash: poolMeta.contentHash,
          choices: ["ignore", "sync", "revert"]
        }
      }]
    }
  }
  return { ok: true, warnings: [] }
}

// src/infra/frozen/proof-reader.ts（v3 新增）
import { readFrozenImmutable, FrozenBody, FrozenXenonMetaBase } from "./immutable"
import { z } from "zod"

export const ProofVerdictSchema = z.enum(["PASSED", "FAILED", "ERROR"])
export const ReadFrozenProofResultSchema = z.object({
  ok: z.boolean(),
  frozen: z.object({
    verdict: ProofVerdictSchema,
    probeResults: z.array(z.unknown()),
    contentHash: z.string()
  }).optional(),
  error: z.object({
    code: z.string(),
    message: z.string()
  }).optional()
})
export type ReadFrozenProofResult = z.infer<typeof ReadFrozenProofResultSchema>

export function readFrozenProof(frozenPath: string): ReadFrozenProofResult {
  return readFrozenImmutable(frozenPath, (raw) => {
    // 校验 body schema（proof specific）
    const verdict = raw.verdict
    if (typeof verdict !== "string" || !["PASSED", "FAILED", "ERROR"].includes(verdict)) {
      return { ok: false, error: { code: "IAP_PROOF_VERDICT_INVALID", message: `Unknown verdict: ${verdict}` } }
    }
    return {
      ok: true,
      frozen: {
        verdict: verdict as "PASSED" | "FAILED" | "ERROR",
        probeResults: Array.isArray(raw.probeResults) ? raw.probeResults : [],
        contentHash: ""  // 内部填
      }
    }
  }) as ReadFrozenProofResult
}
```

// src/cli/pool/verify.ts（v3 走公开 API）
import { readFrozenProof } from "../../infra/frozen/proof-reader"
import { isUpstream, getLifecycle } from "./lifecycle"

export async function verify(poolId: string, proofId: string): Promise<Verdict> {
  // 1. 校验 lifecycle
  const meta = await readMeta(poolId)
  if (isUpstream(meta.type)) {
    return {
      ok: false,
      error: {
        code: "IAP_POOL_LIFECYCLE_MISMATCH",      // ← v3 显式（修细节 10）
        axis: "INTENT",
        action: "YIELD_TO_HUMAN",
        message: `Pool ${poolId} is upstream (${meta.type}); verify requires downstream (audit/journal)`,
        context: { poolId, type: meta.type, lifecycle: "upstream" }
      }
    }
  }

  // 2. 读 proof verdict via infra 公开 API（不直读文件）
  const frozenPath = join(projectRoot, ".openxenon", "proofs", proofId, "frozen.json")
  const result = readFrozenProof(frozenPath)
  if (!result.ok || !result.frozen) {
    return {
      ok: false,
      error: {
        code: "IAP_POOL_VERIFY_PROOF_READ_FAILED",
        axis: "INTENT",
        action: "YIELD_TO_HUMAN",
        message: `Failed to read proof ${proofId} frozen.json`,
        context: { proofId, proofError: result.error }
      }
    }
  }

  // 3. 写 verifiedBy
  const verifiedBy = {
    kind: "proof" as const,
    id: proofId,
    verdict: result.frozen.verdict,
    verifiedAt: new Date().toISOString()
  }
  meta.verifiedBy = verifiedBy
  if (result.frozen.verdict === "PASSED") {
    meta.status = "verified"
  }
  // FAIL 时 status 保持 finalized（v2 决策）
  meta.contentHash = await sha256File(join(poolDir(poolId), "content.md"))
  await writeMeta(poolId, meta)

  return {
    ok: true,
    verdict: result.frozen.verdict,
    status: meta.status,
    verifiedBy
  }
}

### Work → Pool（work 完成**原子**生成 journal）

```bash
oxn work finalize <work-id>
```

1. 校验 overallStatus = passed
2. **两阶段原子写入** journal：
   - 临时目录 `.pools/.tmp/POOL-J001-.../` 写 content.md + meta.json
   - 完整性验证（heading 校验 + meta schema）
   - `rename()` 原子移动到 `pools/journal/POOL-J001-.../`
3. 写 `journal.producedBy = { kind: "work", id, generator: "work-finalize" }`

### Work → Pool（audit 手动创建 + 接 proof verdict）

```bash
# 1. 人工创建 audit
oxn pool create POOL-A<NNN>-xxx --type audit
# 编辑 content.md
oxn pool finalize POOL-A<NNN>-xxx

# 2. 用 proof 验证 audit 结论
oxn proof create check-xxx
oxn proof probe add check-xxx shell-exec --input-json '{"command":"..."}'
oxn proof run check-xxx
oxn pool verify POOL-A<NNN>-xxx --proof check-xxx
# → readFrozenProof() → 写 verifiedBy + 切 status=verified（PASS）/ 保持 finalized（FAIL）
```

## AI 友好命令：draft 不调 $EDITOR

`oxn pool draft <id>` 只返回文件路径，**不**调 $EDITOR。

**AI 流程**：
1. `oxn pool draft POOL-D001-xxx` → 拿到 path
2. `Read` + `Write` 编辑 content.md
3. `oxn pool finalize POOL-D001-xxx` 校验

**人类流程**：CLI 检测到 TTY → 自动调 `$EDITOR`。

## 反模式

- ❌ 不要把 5 类池 heading 混着用——heading 校验会 fail
- ❌ 不要绕过 `oxn pool finalize` 直接改 meta.json.status
- ❌ 不要在 content.md 写代码改动记录——归 `.changes/<version>-<slug>.md`
- ❌ 不要把 `forges/` 旧文档当池条目用
- ❌ 不要 `oxn work create` 不传 `--source-pool` 又想引用池内容
- ❌ 不要在下游池手写 `producedBy.generator` 字段——work finalize 会覆盖
- ❌ 不要 `oxn pool verify` 上游池——返回 `IAP_POOL_LIFECYCLE_MISMATCH`
- ❌ 不要在 content.md 用 `## 3. How —— xxx` 数字前缀 heading——会被解析器 strip 掉

## 失败处理

| 错误码 | 触发 | AI 行动 |
|---|---|---|
| `IAP_POOL_FINALIZE_MISSING_HEADINGS` | 缺必填 heading | 读 `error.context.missingHeadings[]` 补 |
| `IAP_POOL_SOURCE_HASH_DRIFT` | work 副本 ≠ pool 当前 | 报告人类 3 选 1：忽略 / 同步 / 回滚 |
| `IAP_POOL_VERIFY_PROOF_READ_FAILED` | 读 frozen.json 失败 | 检查 proof 是否存在 + 跑过 |
| `IAP_POOL_LIFECYCLE_MISMATCH` | 上游池调 verify / 下游池调 consume | 改用正确生命周期命令 |
| `IAP_POOL_JOURNAL_SKELETON_INVALID` | 骨架自身校验失败 | 这是 v3 工程层 bug，跑 `bun scripts/check-heading-skeleton.ts` 验 |
```
