# v0.6.3 — Asset 分级 + Token 经济学

> **Sprint 周期**：3 周（W1-W3）
> **前置依赖**：v0.6.1（Daemon + Token 统计已就位）
> **核心交付**：Asset scope 字段 + 上下文注入策略 + OXNRC 配置 + 重复检测 + Hall 观测面板
> **架构层**：L0-Schema（scope 字段）+ L2-Intent（注入策略）+ L3-CLI（OXNRC）

---

## 0. 目标与动机

v0.6.0 的 OXN Engine 把所有 Asset 无差别注入到 Skill 上下文，**没有分级**：
- 工程师定的领域模型（必须全量）vs 单场景 Blueprint（按需加载）混在一起
- Token 消耗无法精细化控制
- KV 缓存命中率低（每次上下文变化导致整段重算）

参考 [Harness Engineering](https://mp.weixin.qq.com/s/nBtSvz9PruWe8R2UXUwQwA) 文章的 Rules 分级（**L1 核心 alwaysApply / L2 场景按需加载**），v0.6.3 引入 Asset 分级。

### 关键决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 分级粒度 | `always` / `context` / `lazy` 三档 | 对应 Harness 的 L1/L2 + 未来可扩展 |
| 注入策略 | L2-Intent 统一调度 | 保持 L0 Lambda 真空 |
| Token 估算 | 静态权重（asset / proof / insight 各类） | v0.6.3 不读 LLM SDK |
| KV 缓存优化 | scope=always 标记 + 稳定前缀 | 利用 Transformer 缓存机制 |
| 重复检测 | 启动期扫描 + Hall 警告 | 不阻断，作为提示 |

## 1. 核心概念：Asset scope

```typescript
// packages/engine/src/kernel/schemas/asset-scope-schema.ts (L0)
import { z } from 'zod'

export const AssetScopeSchema = z.enum(['always', 'context', 'lazy'])
export type AssetScope = z.infer<typeof AssetScopeSchema>

// 注入策略
//
// always:   每次 Skill 调用必注入（工程师的"铁规"）
//           - Domain.term / Domain.ban / Domain.invariant（核心不变量）
//           - Blueprint.slot（核心流程）
//           默认值。修改会影响 KV 缓存命中率
//
// context:  关键词触发式注入
//           - Domain.## Stack（特定技术栈）
//           - Blueprint.observe（特定观察项）
//           触发词：work 名 / 任务名 / Blueprint 名
//
// lazy:     按需注入（仅在 LLM 显式 query 时）
//           - Domain.## Example（示例）
//           - Blueprint.examples（代码片段）
//           默认不进入 Skill 上下文，LLM 需主动拉取
```

```oxl

  }
```

**兼容**：未指定 scope 的 Domain 默认 `always`（向后兼容）。

### 2.2 Blueprint 语法扩展

```oxl
blueprint "dev-workflow" {
  scope: context                   # 新增字段
  
  slot "build" { ... }
  slot "test" { deps = ["build"] }
}
```

**Scope 选择指南**：

| Asset 类型 | 推荐 scope | 理由 |
|---|---|---|
| Domain.term | always | 术语一致性是协作底线 |
| Domain.ban | always | 防止漂移 |
| Domain.invariant | always | 机器可校验的红线 |
| Domain.## Stack | context | 特定技术栈才需要 |
| Domain.## Example | lazy | 示例按需 |
| Blueprint.slot | always | 流程必注入 |
| Blueprint.observe | context | 观察项按需 |
| Blueprint.examples | lazy | 示例按需 |

## 3. 上下文注入策略（`packages/engine/src/Intent/inject-strategy.ts`）

### 3.1 算法

```typescript
export interface InjectContext {
  workName: string
  taskName?: string
  blueprintName?: string
  triggerKeywords: string[]      // 从 work/task/blueprint 名提取
}

export interface InjectionPlan {
  always: Asset[]                // 必注入
  context: Asset[]               // 关键词匹配后注入
  lazy: AssetRef[]               // 不注入，但提供 query 接口
  estimatedTokens: {
    always: number
    context: number
    lazy: number                 // 不计入
  }
}

export function planInjection(
  context: InjectContext,
  allAssets: Asset[]
): InjectionPlan {
  const plan: InjectionPlan = {
    always: [],
    context: [],
    lazy: [],
    estimatedTokens: { always: 0, context: 0, lazy: 0 }
  }

  for (const asset of allAssets) {
    const scope = asset.scope ?? 'always'
    
    if (scope === 'always') {
      plan.always.push(asset)
      plan.estimatedTokens.always += estimateTokens(asset)
    } else if (scope === 'context') {
      // 关键词匹配
      if (matchesTrigger(asset, context.triggerKeywords)) {
        plan.context.push(asset)
        plan.estimatedTokens.context += estimateTokens(asset)
      } else {
        plan.lazy.push(asset)
        plan.estimatedTokens.lazy += estimateTokens(asset)
      }
    } else {  // lazy
      plan.lazy.push(asset)
      plan.estimatedTokens.lazy += estimateTokens(asset)
    }
  }

  return plan
}

function matchesTrigger(asset: Asset, keywords: string[]): boolean {
  const assetName = asset.name.toLowerCase()
  return keywords.some(k => assetName.includes(k.toLowerCase()))
}

function estimateTokens(asset: Asset): number {
  // v0.6.3 静态估算：字符数 / 4 (粗略)
  return Math.ceil(JSON.stringify(asset).length / 4)
}
```

### 3.2 注入顺序（KV 缓存友好）

```
[System Prompt] → [always Asset 1] → [always Asset 2] → ... → [context 触发 Asset] → [work context]
                  ↑ 稳定前缀（高 cache 命中率）
```

**关键**：always Asset 必须稳定（不允许运行时变）。如果 always Asset 内容变化，会导致后续所有 token 缓存失效。

### 3.3 lazy Asset query

## 6. Asset 重复检测（`packages/engine/src/Asset/dup-detector.ts`）

### 6.1 算法

```typescript
export interface DuplicateReport {
  duplicates: DuplicateGroup[]
  suggestions: Suggestion[]
}

export interface DuplicateGroup {
  kind: 'term' | 'ban' | 'invariant'
  assets: string[]                // 涉及的 Domain 名
  values: string[]                // 重复的内容
  similarity: number              // 0-1
}

export function detectDuplicates(domains: Domain[]): DuplicateReport {
  const termMap = new Map<string, string[]>()    // normalized value → domain names
  const banMap = new Map<string, string[]>()
  const invMap = new Map<string, string[]>()
  
  for (const domain of domains) {
    for (const term of domain.terms ?? []) {
      const key = normalizeValue(term.value)
      if (!termMap.has(key)) termMap.set(key, [])
      termMap.get(key)!.push(domain.name)
    }
    for (const ban of domain.bans ?? []) {
      const key = normalizeValue(ban)
      if (!banMap.has(key)) banMap.set(key, [])
      banMap.get(key)!.push(domain.name)
    }
    for (const inv of domain.invariants ?? []) {
      const key = normalizeValue(inv)
      if (!invMap.has(key)) invMap.set(key, [])
      invMap.get(key)!.push(domain.name)
    }
  }
  
  const duplicates: DuplicateGroup[] = []
  for (const [value, assets] of termMap) {
    if (assets.length > 1) {
      duplicates.push({ kind: 'term', assets, values: [value], similarity: 1.0 })
    }
  }
  // ... banMap, invMap 同理
  
  return { duplicates, suggestions: generateSuggestions(duplicates) }
}

function normalizeValue(s: string): string {
  return s.toLowerCase().replace(/\s+/g, ' ').trim()
}
```

### 8.2 config validate

```typescript
// packages/cli/src/commands/config.ts
export async function validateConfig(): Promise<ConfigReport> {
  const cfg = await loadOxnrc()
  const domains = await loadAllDomains()
  const blueprints = await loadAllBlueprints()
  
  const plan = planInjection(
    { workName: 'all', triggerKeywords: cfg.context.triggerKeywords },
    [...domains, ...blueprints]
  )
  
  const total = plan.estimatedTokens.always + plan.estimatedTokens.context
  const fits = total <= cfg.context.tokenBudget
  
  return {
    budget: cfg.context.tokenBudget,
    actual: total,
    fits,
    breakdown: {
      always: plan.estimatedTokens.always,
      context: plan.estimatedTokens.context,
      lazy: plan.estimatedTokens.lazy
    },
    stablePrefixSize: plan.always.length,
    variableSuffixSize: plan.context.length,
    cacheKeyStability: 'high'  // v0.6.3 简化
  }
}
```

### 8.3 dup-detector 跨 Domain 抽取建议

```typescript
function generateSuggestions(duplicates: DuplicateGroup[]): Suggestion[] {
  return duplicates.map(dup => {
    if (dup.similarity === 1.0) {
      return {
        severity: 'warning',
        message: `完全重复: ${dup.kind} "${dup.values[0]}" 出现在 ${dup.assets.length} 个 Domain`,
        action: '建议抽取到 shared-domain.oxn 或 BaseDomain',
        example: dup.kind === 'term' 
          ? `// shared-domain.oxn\ndomain "BaseDomain" {\n  term {\n    "${dup.values[0]}" = "..."\n  }\n}`
          : ''
      }
    }
    return {
      severity: 'info',
      message: `高相似度: ${dup.kind} 在 ${dup.assets.join(', ')}`,
      action: '考虑上下文差异或合并'
    }
  })
}
```

### 9.1 典型场景：调整 Token 预算

```bash
# 1. 工程师想增加预算（业务复杂）
$ oxn config set context.tokenBudget 25000

# 2. 验证当前 Asset 是否仍 fit
$ oxn config validate
# → All Asset injections fit in 25000 token budget ✓
# → Stable prefix: 12 always-assets, 8500 tokens
# → Variable suffix: 3 context-assets (triggered), 1200 tokens
# → ⚠️  Lazy assets not counted (12 available on demand)

# 3. 想看具体哪些 Asset 注入
```


## 10. 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| scope 修改影响 KV 缓存命中率 | 中 | 中 | Hall 显示 cache stability 评分；提供 migration guide |
| lazy Asset LLM 不主动 query | 中 | 低 | Skill 提示 + Hall 统计 lazy 调用率 |
| 重复检测 false positive | 中 | 低 | 仅 warning，不阻断；阈值可调 |
| Token 估算不准确 | 高 | 低 | v0.6.3 粗粒度估算，v0.7+ 真实计数 |
| 触发词配置错误 | 中 | 中 | Hall 显示"未触发的 context Asset"警告 |
| OXL grammar 兼容破坏 | 低 | 高 | 旧 .oxn 文件 scope 默认 always，零迁移成本 |
