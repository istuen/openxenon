# v0.6.3 — Insight 收集层（强制人工审核）（原 v0.6.2）

> **Sprint 周期**：3 周（W1-W3）
> **前置依赖**：v0.6.1（Daemon + insight-raw 池已就位）
> **核心交付**：trace 结构化 + insight-raw 池 + CLI 子命令 + 跨 Work 模式初探
> **架构层**：L2-Insight（核心逻辑）+ L3-CLI（命令）
> **核心约束**：**强制人工审核**——AI 不直接覆盖 Asset

---

## 0. 目标与动机

v0.6.1 已经把 Insight 信号落入 `pools/insight-raw/`，但缺少：
1. **结构化提取** — trace.jsonl 中的 raw 事件没有专门的 Insight 字段
2. **可读展示** — 工程师看不到这些 raw Insight
3. **跨 Work 模式** — 多次相同失败没有被聚合
4. **强制人工审核链路** — 没有任何从 raw → audit → Asset 的通道

v0.6.2 一次性补齐这四项。但**仍然只是"收集 + 审核"最弱形式**——真正的 Insight 工程化（反哺、归档、可视化）留到 v0.7。

### 关键决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| Insight 提取方式 | Daemon 触发 + L0 纯函数聚合 | 保持 L0 Lambda 真空 |
| 强制人工审核链路 | CLI 子命令 `approve/reject` | 不让 AI 直接写 Asset |
| 跨 Work 模式 | 同 Domain ≥ 3 次相同 fail 触发 | 简单阈值，避免误报 |
| Insight 不可篡改 | hash 链 + 0o444 权限 | 沿用 frozen.json 模式 |
| 反馈循环 | audit pool 写完后转给 v0.7 处理 | v0.6.2 不闭环 |

### 2.1 trace.jsonl 结构化（`src/work/trace.ts` 扩展）

**新增字段**（v0.6.2 追加，**向后兼容**）：

```typescript
type TraceEvent =
  | { type: 'work.created'; ...原有字段; insightRefs?: never }
  | { type: 'work.locked'; ...原有字段; insightRefs?: never }
  | { type: 'task.run'; taskName: string; duration: number; insightRefs?: never }
  | { type: 'task.submit'; taskName: string; verdict: 'passed' | 'failed'; insightRefs?: string[] }
  | { type: 'probe.run'; probeName: string; result: 'pass' | 'fail' | 'inconclusive'; insightRefs?: never }
  | { type: 'asset.violation'; domain: string; term: string; severity: 'warn' | 'error'; insightRefs?: string[] }  // 新增
  | { type: 'intent.drift'; originalIntent: string; actualIntent: string; insightRefs?: string[] }              // 新增
  | { type: 'round.passed'; round: number; insightRefs?: never }
  | { type: 'round.failed'; round: number; failures: string[]; insightRefs?: string[] }                       // 扩展
```

**`insightRefs` 字段**：触发 Insight 提取时，附加 insight-raw 文件路径。

**触发点**（在 work.ts 中插入）：
- `task.submit` verdict=failed → 提取 Insight
- `asset.violation` 触发 → 提取 Insight
- `intent.drift` 触发 → 提取 Insight
- `round.failed` 触发 → 提取 Insight

### 2.2 Insight 原始池（`src/insight/insight-pool.ts`）

**位置**：`.openxenon/pools/insight-raw/`

**写入格式**：
```typescript
interface InsightRaw {
  id: string                    // insight-<timestamp>-<workName>-<n>
  createdAt: string             // ISO timestamp
  workName: string
  round: number
  type: InsightType
  summary: string               // 人类可读
  evidence: {
    traceRefs: string[]         // trace.jsonl:line 引用
    violationCount?: number
    failurePatterns?: string[]
  }
  status: 'raw'                 // 固定
  hash: string                  // sha256 of (id + createdAt + workName + evidence)
  prevHash: string | null       // hash 链（指向上一条 insight）
}

type InsightType =
  | 'asset_violation'           // 触发了 asset 红线
  | 'intent_drift'              // AI 偏离了原始意图
  | 'round_failure'             // round 失败
  | 'probe_unstable'            // probe 间歇性失败
  | 'cross_work_pattern'        // 跨 Work 模式（v0.6.2 新增）
```

**hash 链**：每条 insight 引用上一条的 hash，形成不可篡改链。

**权限**：写入后 `chmod 0o444`（与 frozen.json 一致）。

### 2.3 跨 Work 模式识别（`packages/engine/src/Insight/cross-work.ts`）

**L0 纯函数**（无 IO）：

```typescript
export interface CrossWorkPattern {
  domain: string
  pattern: string                // e.g. "C1: ESM project forbids require()"

  lastSeen: string

  confidence: number             // 0-1
}

export function detectCrossWorkPatterns(

  // 2. 过滤 occurrences >= 3
  // 3. 计算 confidence（基于时间跨度 + 多样性）
  // 4. 返回排序后的 patterns

```

**算法**：
- 阈值：同 domain + 同 pattern ≥ 3 次
- 时间窗口：默认 30 天（可配）
- confidence 计算：`occurrences / 10 * (1 - (timeSpan / 30days))`

**输出**：自动写入 `insight-raw/<workName>-cross-<timestamp>.json`，type = `cross_work_pattern`。

### 2.4 CLI 子命令（`packages/cli/src/commands/insight.ts` 扩展）

**新增子命令**：

```bash
# 列表
oxn insight list [--type <type>] [--status raw|audit|archived] [--limit N]

# 详情
oxn insight show <id>

# 提升到 audit pool（v0.6.2 引入）
oxn insight promote <id>
  --target-asset <domain|blueprint>
  --target-kind <invariant|term|ban>
  [--note <text>]

# 审核（v0.6.2 强制人工）
oxn insight approve <id>     # 写入 Asset 草案（仍需 validate 才能正式入库）
oxn insight reject <id> [--reason <text>]

# 归档（30 天未 review 自动；也可手动）
oxn insight archive [--before <date>]
```

**强约束**：
- `promote` 仅写 audit pool，**不**直接覆盖 Asset
- `approve` 写 Asset **草案**（`.oxn.draft`），需 `oxn domain validate` 才能正式入库
- `reject` 写回 audit pool + 标记 `rejected`，永不删除

**approve 流程示意**：
```
insight-raw/        insight-audit/         assets/                    assets/        (正式)
   *.json  ──promote──→  *.json ──approve──→  *.oxn.draft  ──validate──→  *.oxn
                                                                              ↑
                                                                      validate
```

### 2.5 Insight 归档（`packages/engine/src/Insight/archiver.ts`）

**自动归档触发**：
- 每日 00:00 由 Daemon 触发
- 30 天前创建 + status=raw → 归档到 `insight-archive/`
- 30 天前创建 + status=audit 且 rejected → 归档

**手动归档**：
- `oxn insight archive --before 2026-06-01`

**归档格式**：原文件移动到 `insight-archive/<year>-<month>/<id>.json`，不修改内容。

## 5. 关键代码片段

### 5.1 cross-work.ts 核心算法

```typescript
// packages/engine/src/Insight/cross-work.ts (L0 纯函数)
import type { InsightRaw } from './types'

export interface CrossWorkPattern {
  domain: string
  pattern: string
  occurrences: number
  workNames: string[]
  firstSeen: string
  lastSeen: string
  suggestedInvariant: string
  confidence: number
}

const PATTERN_THRESHOLD = 3
const TIME_WINDOW_DAYS = 30

export function detectCrossWorkPatterns(
  rawInsights: InsightRaw[],
  now: Date = new Date()
): CrossWorkPattern[] {
  const cutoff = new Date(now.getTime() - TIME_WINDOW_DAYS * 86400_000)

  // 1. 按 (domain, pattern) 分组
  const groups = new Map<string, InsightRaw[]>()
  for (const insight of rawInsights) {
    if (insight.type !== 'asset_violation') continue
    if (new Date(insight.createdAt) < cutoff) continue
    const key = `${insight.evidence.domain}::${insight.summary}`
    if (!groups.has(key)) groups.set(key, [])
    groups.get(key)!.push(insight)
  }

  // 2. 过滤 + 计算 confidence
  const patterns: CrossWorkPattern[] = []
  for (const [key, list] of groups) {
    if (list.length < PATTERN_THRESHOLD) continue
    const [domain, pattern] = key.split('::')
    const workNames = [...new Set(list.map(i => i.workName))]
    const firstSeen = list.reduce((a, b) => a.createdAt < b.createdAt ? a : b).createdAt
    const lastSeen = list.reduce((a, b) => a.createdAt > b.createdAt ? a : b).createdAt
    const timeSpan = (new Date(lastSeen).getTime() - new Date(firstSeen).getTime()) / 86400_000
    const confidence = Math.min(1, list.length / 10 * (1 - timeSpan / TIME_WINDOW_DAYS))

    patterns.push({
      domain,
      pattern,
      occurrences: list.length,
      workNames,
      firstSeen,
      lastSeen,
      suggestedInvariant: generateInvariantSuggestion(pattern, list.length),
      confidence
    })
  }

  // 3. 按 confidence 降序
  return patterns.sort((a, b) => b.confidence - a.confidence)
}

function generateInvariantSuggestion(pattern: string, occurrences: number): string {
  return `${pattern} (observed ${occurrences} times across multiple works)`
}
```

### 5.2 promote CLI 流程

```typescript
// packages/cli/src/commands/insight.ts
export async function promoteInsight(id: string, options: PromoteOptions): Promise<void> {
  // 1. 读取 raw insight
  const insight = await readInsightRaw(id)
  if (!insight) throw new IAPError('OXNI_INSIGHT_NOT_FOUND', { id })

  // 2. 校验 target asset 存在
  const targetPath = await resolveAssetPath(options.targetAsset, options.targetKind)
  if (!targetPath) throw new IAPError('OXNI_INSIGHT_TARGET_ASSET_MISSING', {
    asset: options.targetAsset,
    kind: options.targetKind
  })

  // 3. 生成 audit 条目（含 source insight 引用）
  const auditEntry: AuditInsight = {
    id: insight.id,
    promotedAt: new Date().toISOString(),
    promotedBy: process.env.USER ?? 'unknown',
    targetAsset: options.targetAsset,
    targetKind: options.targetKind,
    note: options.note,
    status: 'pending_review',  // 关键：尚未审核
    sourceInsight: {
      workName: insight.workName,
      type: insight.type,
      summary: insight.summary,
      evidence: insight.evidence
    }
  }

  // 4. 写 audit pool（不直接覆盖 Asset）
  await writeInsightAudit(auditEntry)
  await updateInsightRawStatus(id, 'audit')

  console.log(`✓ Insight ${id} promoted to audit pool`)
  console.log(`  → Next: oxn insight approve ${id} to write Asset draft`)
}
```

### 5.3 approve 强制人工提醒

```typescript
export async function approveInsight(id: string): Promise<void> {
  const audit = await readInsightAudit(id)
  if (!audit) throw new IAPError('OXNI_INSIGHT_NOT_FOUND', { id })

  // 强约束：强制人工审核
  if (process.env.OXN_AUTO_APPROVE === 'true') {
    console.warn('⚠️  OXN_AUTO_APPROVE=true detected. Are you sure?')
    console.warn('   This bypasses the "强制人工审核" constraint.')
    console.warn('   Press Ctrl+C within 5 seconds to cancel...')
    await new Promise(resolve => setTimeout(resolve, 5000))
  }

  // 1. 生成 Asset 草案
  const draftPath = await writeAssetDraft(audit)
  await updateInsightAuditStatus(id, 'approved')

  console.log(`✓ Insight ${id} approved`)
  console.log(`  → Asset draft written: ${draftPath}`)
  console.log(`  → Next: oxn ${audit.targetKind} validate ${audit.targetAsset} to finalize`)
}
```

## 6. 用户体验流程

### 6.1 典型流程 A：单 Work 失败 → 提取 Insight → 人工审核

```bash
# 1. Work 失败（自动）
$ oxn work run my-feature
# → Round 1 failed: 3 files modified outside MemberContext scope

# 2. Daemon 自动落 raw insight
$ cat .openxenon/pools/insight-raw/my-feature-2026-07-15-001.json
# {
#   "id": "insight-my-feature-2026-07-15-001",
#   "type": "asset_violation",
#   "summary": "3 files modified outside MemberContext domain scope",
#   ...
# }

# 3. 工程师查看
$ oxn insight list
# 1. insight-my-feature-2026-07-15-001   asset_violation   raw

# 4. 提升到 audit pool
$ oxn insight promote insight-my-feature-2026-07-15-001 \
    --target-asset MemberContext --target-kind invariant \
    --note "Add invariant to prevent out-of-scope file modifications"
# → ✓ Promoted to insight-audit/

# 5. 人工审核
$ oxn insight show insight-my-feature-2026-07-15-001
# (查看完整 evidence + trace 引用)

$ oxn insight approve insight-my-feature-2026-07-15-001
# → ✓ Asset draft written: .openxenon/assets/domain/MemberContext.oxn.draft
# → Next: oxn domain validate MemberContext

# 6. 正式入库
$ oxn domain validate MemberContext
# → ✓ Invariant added, planLock 重新计算
```

## 7. 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 误报（false positive）跨 Work 模式 | 中 | 中 | 阈值 3 次 + confidence 评分；低 confidence 不 promote |
| 强制人工审核被绕过 | 低 | 高 | `OXN_AUTO_APPROVE` 环境变量 + 5 秒延迟警告 |
| hash 链断裂 | 低 | 中 | 每次写入校验 prevHash；断裂时拒绝写入 |
| insight-audit 池膨胀 | 中 | 低 | 30 天归档策略 |
| approve 写 Asset 草案后未 validate | 中 | 中 | draft 文件带 `.draft` 后缀；domain validate 时检测 |
| OXN_AUTO_APPROVE env var 滥用 | 低 | 中 | 启动日志警告；v0.7 引入审计日志 |
