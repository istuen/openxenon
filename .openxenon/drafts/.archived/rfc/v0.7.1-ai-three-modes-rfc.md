## 0. 背景与动机

v0.6.1-alpha.0 已落地 Insight E4 行为观测，但 **AI 执行监督程度仍是二元**（Guided 默认 / 无监督实验）。现实中 AI 协作按工程师监督程度分**三档**：

| 模式 | 监督 | 验证 | 当前对应 |
|---|---|---|---|
| **Guided** | 全程 | 严格 Probe + 人工 review | v0.6.1 默认 |
| **Adaptive** | 跳过 action 重放 | Probe 警告级 | ❌ 未实现 |
| **Unmanaged** | 无监督 | 仅 lint / Hall 告警 | ❌ 未实现（实验性） |

v0.7.1 一次性补齐三档分级，让 Insight 模式推荐能区分"工程师是否在场"。

---

## 1. 三模式契约

### 1.1 Guided（默认 · 80% 场景）

- **特征**：工程师每轮都看 Insight / diff
- **验证**：所有 Probe PASSED 才进 finalize
- **CLI**：`oxn work --mode guided`（默认）
- **Insight 关联**：每次 verdict FAIL 必写 Insight

### 1.2 Adaptive（15% 场景 · debug/重构）

- **特征**：工程师跳过 action 重放，但仍看 Probe 结果
- **验证**：Probe 警告级（YELLOW flag 透传，不阻断）
- **CLI**：`oxn work --mode adaptive`
- **Insight 关联**：仅在 RED flag / INCONCLUSIVE 时写 Insight

### 1.3 Unmanaged（5% 场景 · 实验/Hackathon）

- **特征**：工程师放手让 AI 跑，仅看最后产出
- **验证**：仅 lint + 类型检查，无 Probe
- **CLI**：`oxn work --mode unmanaged`
- **Insight 关联**：仅在异常时写 Insight（probability 5%）
- **Hall 强提示**：`/hall/insight/` 顶部 banner："⚠️ 5 个 Unmanaged Work 未审阅"

## 2. 实现细节

### 2.1 模式开关注入点

`packages/engine/src/Work/dual-state-exec.ts::runWork()`：

```ts
const mode = opts.mode ?? 'guided'  // 来自 CLI --mode
const guardLevel = {
  guided: 'strict',
  adaptive: 'warn',
  unmanaged: 'lint-only'
}[mode]

// 在写 .run/state.json 时记 mode
state.mode = mode
state.guardLevel = guardLevel
```

### 2.2 Probe 警告级 vs 严格级

`packages/engine/src/Proof/runner.ts::executeProbe()`：

```ts
const trustBaseline = mode === 'adaptive' ? 'warn' : 'strict'
const result = await executeObservation(...)
const verdict = judge(result, { trustBaseline })
// adaptive 下 YELLOW flag 不影响 verdict，但仍写 interferenceFlags
```

### 2.3 reputation.json 累积

v0.6.2 已有 `reputation.json`（probe-stats.json）。v0.7.1 扩展为：

```json
{
  "schemaVersion": 2,
  "perProbe": { "fs-exists": { "passRate": 0.96, "..." } },
  "perMode": {
    "guided":    { "works": 12, "avgRounds": 2.3 },
    "adaptive":  { "works": 4,  "avgRounds": 1.8 },
    "unmanaged": { "works": 1,  "avgRounds": 1.0 }
  }
}
```

## 3. Insight 模式推荐升级

v0.7.0 模式库基于 `cross_work_pattern` 类型。v0.7.1 新增 `mode_recommendation`：

```json
{
  "id": "mode-rec-2026-12-C1",
  "type": "mode_recommendation",
  "domain": "RefactorContext",
  "suggestedMode": "adaptive",
  "rationale": "C1: 此 Domain 80% 的 Work 走 adaptive，平均 1.8 round，verdict 全 PASSED",
  "confidence": 0.78,
  "status": "open"
}
```

`oxn insight apply mode-rec-XXX` → 写入 `OxnConfig.aiDefaultMode = "adaptive"`。

## 6. 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| AI 在 unmanaged 模式失控 | 中 | 高 | Hall 顶部 banner 强提示；verdict FAIL 强制 Insight |
| 模式推荐误判 | 中 | 中 | 工程师显式 `oxn insight apply` 审批 |
| 模式分布失衡（80% unmanaged） | 低 | 高 | Hall 协同健康度告警 |
