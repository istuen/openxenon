# 产品手册

> **受众**：OpenXenon 使用者（工程师 + AI Agent 协作者）
>
> **核心命题**：OpenXenon 是工程师定义 AI Agent 协作边界的工具。
>
> **三方协作模型**：工程师（Asset 管理 + Proof 审查）+ AI Agent（via Skill，Work 内自主工作）+ OXN Engine（被动响应 CLI，验证 + 记录）。OXN 彻底不判——只记录客观事实，判定权归工程师。
