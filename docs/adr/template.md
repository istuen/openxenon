# ADR Template

> 复制此模板到新文件，重命名为 `NNNN-<kebab-case-title>.md`。

```markdown
# NNNN. <Title>

**Status**: Proposed | Accepted | Deprecated | Superseded by 0NNN
**Date**: YYYY-MM-DD

## Context

面临什么问题？背景是什么？有哪些约束？

## Decision

我们做了什么决定？

## Consequences

正面影响：
- ...

负面影响：
- ...

## Alternatives Considered

### Alternative 1: <name>
- 优点：...
- 缺点：...

### Alternative 2: <name>
- 优点：...
- 缺点：...

## References

- 相关文档
- 相关 issue / PR
```

## 状态

| Status | 含义 |
|---|---|
| **Proposed** | 提案中，未最终决定 |
| **Accepted** | 已接受，正在生效 |
| **Deprecated** | 已废弃（不推荐使用） |
| **Superseded by 0NNN** | 被新 ADR 取代（指向新文件） |
