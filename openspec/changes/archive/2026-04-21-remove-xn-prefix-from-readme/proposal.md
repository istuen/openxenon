## Why

README 中的 Xn* 前缀仅用于代码层面标识，文档阅读时造成干扰。需移除文档中的 Xn* 前缀，保持阅读流畅性。

## What Changes

- 移除 README 中的 Xn* 前缀
- XnStage → Stage
- XnBlueprint → Blueprint
- XnProof → Proof
- XnSpec → Spec
- XnTask → Task
- XnAction → Action
- XnSample → Sample
- XnStore → Store
- XnSandbox → Sandbox
- XnRadar → Radar
- XnTransport → Transport

## Capabilities

### Modified Capabilities

- `xn-readme`: 更新 README 文档

## Impact

- 仅修改 README.md
- 不影响代码实现
