```markdown
# 1. 系统介绍

## 什么是 OpenXenon

OpenXenon 是一个实验性框架，探索如何让工程师与 AI 更有效地协作。

AI 模型执行效率高、探索能力强，但也会推测出错、出现幻觉。
工程师懂业务、懂技术，能设计方案、沉淀经验。
OpenXenon 要解决的问题是：**如何把工程师的经验转化为 AI 能理解并执行的指令，同时降低 Token 成本。**

## 系统架构

```
工程师
   │
   ▼
AI 模型（通过 /oxn-forge、/oxn-task 与系统交互）
   │
   ▼
oxn CLI（命令入口）
   │
   ├──► Kernel（纯函数判定）
   │
   ├──► Infra（文件系统和进程操作）
   │
   └──► Arsenal（内置资产）
```

## 核心价值

| 价值 | 说明 |
|------|------|
| **经验资产化** | 工程师的判断变成 AI 可执行的约束 |
| **结果可验证** | AI 的执行结果通过物理观测确认 |
| **资产可积累** | 好的约束可以复用和沉淀 |
```
